# 0002 - Nessuna chiave di attivazione

Stato: accettata (2026-11-11)

## Contesto

L'originale è vincolato da una licenza a chiave con verifica remota.

## Decisione

Il software è completo al 100% senza chiave: nessuna attivazione, nessuna
funzione bloccata, nessun
controllo di integrità remoto.

## Conseguenze
Ogni installazione ha tutte le funzionalità, per sempre. Il codice e il modello
di dati non devono
prevedere livelli di licenza.
